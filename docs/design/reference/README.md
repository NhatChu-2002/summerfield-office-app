# Summerfield HQ UI Preview

`Summerfield HQ.html` is a standalone preview of the Summerfield HQ interface.

Open the HTML file in a browser to explore the dashboard, navigation, department pages, calendars, folders, projects, locations, reports, and the embedded department tools. The preview automatically uses a local `Preview Admin` identity so no Claude sign-in or account access is required.

## Preview limitations

- Company data is not loaded.
- Changes are not saved or shared.
- Access requests, email drafting, uploads, and other connected services remain unavailable.
- Buttons and forms are kept visible so their layout and interaction flow can be reviewed.

The existing Claude-connected path is preserved. When the same file runs in an environment that provides the Claude bridge, it continues to use the shared identity, database, assets, and room services.
