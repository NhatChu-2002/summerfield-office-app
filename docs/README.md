# Docs

- **`design/reference/`** holds original HQ prototype (`Summerfield HQ.html`) and its notes. It is the visual reference for rebuilding each screen in React. Open it in a browser. It is not runtime code.
- **`design/qa/design-qa.md`** is a dated log of each design check: what was compared, what was verified, and what wasn't. Screenshots are in `design/qa/evidence/`. Add an entry whenever a screen is rebuilt or its design changes.
